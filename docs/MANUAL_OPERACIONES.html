Guía profesional para la gestión del sistema Secretary App mediante Docker.

⚙️ Guía de Configuración
Entorno de Desarrollo

1. Programación y Cambios Visuales

Usa este modo para probar nuevas funciones sin riesgos.

$ docker compose up --build
  • URL: http://localhost:5173
  • Credenciales: admin / admin
  • Datos: FICCIÓN (o copia local en mysql_data)
  • Magia: Hot-Reload (los cambios se ven al instante).
Control de Calidad (Staging)

2. Prueba de "Fuego" antes de subir

Réplica exacta de producción en un puerto separado.

$ ./scripts/deploy.sh -> Seleccionar "Staging"
  • URL: http://localhost:8081
  • Propósito: Verificar que las imágenes optimizadas funcionen bien.
Entorno de Producción

3. Despliegue Final (Uso Real)

El sistema que usan la secretaria y los médicos.

$ ./scripts/deploy.sh -> Seleccionar "Production"
  • URL: http://localhost:8080
  • Datos: REALES (Base de datos persistente)
  • Estabilidad: Auto-reinicio activado.

💾 Respaldo y Seguridad

Scripts automáticos para generar copias de seguridad. Los archivos se guardan en el Escritorio.

Respaldo Prod (Datos Reales)

$ ./scripts/backup_prod.sh

Respaldo Dev (Entorno Pruebas)

$ ./scripts/backup_dev.sh
  • Se genera un archivo .sql.gz comprimido.
  • Se copia automáticamente al Escritorio.

🛠️ Herramientas de Monitoreo

  • Logs en tiempo real: http://localhost:8888 (Dozzle)
  • Salud del Sistema: http://localhost:5001/api/health
  • Rotación de Logs: Activo (Evita llenar el disco).
