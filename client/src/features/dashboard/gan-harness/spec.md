# Dashboard Design Spec

## Goal
Redesign the `/dashboard` of the Secretary App into a state-of-the-art, visually stunning, dark-mode glassmorphism interface.

## Requirements
1. **Glassmorphism Aesthetic**: Use `backdrop-filter: blur()`, semi-transparent dark backgrounds, and subtle neon glows (cyan/purple).
2. **Bento Grid Layout**: Organize the dashboard into a tight grid of cards (`bento-card`).
3. **Data Visualization**: Include visually appealing mockups of stats, a placeholder line chart for patient growth, and a "Pending Requests" queue.
4. **Primary Goal**: Visual excellence. Push for creative leaps—unusual layouts, custom animations, distinctive color work. The design should inspire a "wow" factor.
